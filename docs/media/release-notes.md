The walkthrough contains real application screenshots and actual image-generation results. It is edited, not a real-time speed test. Narration is synthetic speech added in post-production. The historical six-shot film and the new screenshot project are separate runs. Human review is still needed for visual consistency and model artifacts.

This is a **documentation and media showcase**, not a declaration of a production-ready application version. The task panel also gained a keyboard-accessible collapse control, without removing job records.
