# LTSeries 漫剧生产流程评估

更新时间：2026-05-15

> 2026-10-25 公开发布说明：下文为阶段性流程评估记录，不是视觉质量认证。
> “效率分”和“一致性分”来自元数据检查，未测量真实工时或画面相似度；
> 本地末帧只有在云服务能够访问其 URL 时才能参与后续生成。
> 当前部署方式与限制以 [README](../README.zh-CN.md) 和 [部署文档](deployment.md) 为准。

## 结论

LTSeries 已覆盖 AI 漫剧创作者的核心生产链路：剧本录入、AI 解析、美术方向、角色/场景/道具资产、分镜、首帧、视频片段、成片拼接和任务记录。它可以提升单集样片和短篇漫剧的制作效率，尤其适合从文字剧本快速推进到可预览成片。

当前系统不能承诺绝对一致性。原因是通用图片/视频模型不是角色绑定模型，且跨镜头一致性依赖参考图、提示词和人工复核。系统现在已经加入资产参考、上一镜头视频末帧衔接和生产体检，可以把一致性风险显性化并降低发散概率。

## 效率提升点

- 从剧本到资产和分镜可自动生成，减少手工拆解。
- 角色三视图、全身图、头像特写可批量补齐，降低重复提示词工作。
- 分镜首帧和视频可一键补全并拼接，减少逐镜头手动排队。
- 任务记录保留成功/失败状态，便于重试和追踪。
- 生产体检能快速指出缺失资产、缺失视频、缺少引用等阻塞点。
- 效率分和一致性分把“能不能快做”和“能不能稳住角色/场景”拆开，方便创作者决定下一步。

## 一致性能力边界

已具备：

- 分镜解析后会把角色/场景名称归一到真实资产 ID。
- 首帧生成会携带资产参考图。
- 视频生成任务会记录 `reference_image_urls`。
- 可按资产重生成全片，覆盖旧的裸 prompt 结果。

仍有限制：

- 通用模型不能保证 100% 锁脸、锁服装、锁道具。
- 多参考图过多时，模型可能忽略部分参考。
- 新版流水线会在视频生成后抽取视频末帧并保存为 `last_frame_url`，下一镜头生成首帧时优先把它作为连续性参考。
- 最终发布前仍需要人工抽检关键镜头。

## 已执行的改进

- 新增生产体检数据结构和 API：`GET /api/projects/:id/production-audit`。
- 成片页新增“生产流程体检”面板，展示分数、问题和关键指标。
- 生产体检面板新增效率分、一致性分、生产阶段状态和逐镜头一致性抽检。
- 自动流水线已使用资产库参考图和上一镜头画面增强一致性。
- 自动流水线会记录每个镜头的视频末帧，用于后续镜头衔接。
- 手动分镜生成也支持按名称或 ID 匹配角色、场景、道具参考。
- 当前项目已完成按资产重生成，6 个分镜视频任务均带参考图。

## 后续建议

1. 增加关键角色“锁定参考图组”，区分远景、半身、特写使用不同参考。
2. 对视频结果做人工通过/驳回状态，不通过的镜头进入重生成队列。
3. 对每集建立统一 seed、色彩、镜头语言配置，减少批次差异。
4. 若模型侧支持角色一致性模型、R2V 或 LoRA，应优先把它们接入为生产模式。
